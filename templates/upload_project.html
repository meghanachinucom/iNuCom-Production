Spreadsheet Format Guidelines
  • The Excel sheet should contain the following columns from left to right:
    Column A: Project Name  |  Column B: Chapter Name  |  Column C: File Name  |  Column D: Description (Optional)
  • The first row is automatically treated as a header and skipped if it contains terms like "Project" or "File".
  • Existing projects and chapters will be matched automatically by name. New projects/chapters will be created if they do not exist.
  • Each imported file will have its full pipeline stage board initialized (Content stage starts as Open, other stages start as Pending) and will instantly be visible in all artist, lead, and admin trackers.
